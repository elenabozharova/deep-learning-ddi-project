# Project purpose

This repository contains a proof-of-concept reproduction of PolyLLM
using the TwoSIDES/Decagon dataset.

# Current status

All planned reproduction milestones have been implemented.

# Working rules

- Do not modify code unless explicitly requested.
- When explaining implementation, use actual files and outputs.
- Separate verified code behaviour from assumptions.
- Include file paths and function names.
- Compare implementation decisions with the PolyLLM paper.
- Use one real example when tracing data.
